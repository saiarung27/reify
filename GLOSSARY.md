# Glossary of Abbreviations

This document defines the abbreviations used throughout the Reify documentation.

| Abbreviation | Full Name |
|---|---|
| **ARW** | Active Reconsolidation on Write — the process of materializing cross-session inferences at write time rather than read time |
| **BTG** | Bitemporal Transition Graph — a first-class memory type that tracks changes to facts over time with explicit evidence trails |
| **CI** | Continuous Integration — the automated testing and validation pipeline that runs on every commit |
| **CRDT** | Conflict-free Replicated Data Type — a data structure that enables concurrent updates across multiple devices without conflicts |
| **CTE** | Common Table Expression — a temporary result set in SQL that can be referenced within a SELECT, INSERT, UPDATE, or DELETE statement |
| **DRL** | Dialectic Reflection Loop — an implicit pattern inference mechanism combined with adversarial probing for belief validation |
| **IBG** | Identity Bond Graph — a probabilistic graph linking anonymous sessions to devices to users for cross-session identity resolution |
| **MCP** | Model Context Protocol — the standard protocol for AI agent tool integration (e.g., Claude Desktop, Cursor, Windsurf) |
| **NER** | Named Entity Recognition — the process of identifying and classifying named entities in text |
| **RRF** | Reciprocal Rank Fusion — a rank aggregation method used to combine results from multiple retrieval strategies |
| **TTL** | Time To Live — the expiration time for a memory claim before it is forgotten by default |
| **WAL** | Write-Ahead Logging — a journaling method for SQLite that provides crash safety and atomic transactions |
